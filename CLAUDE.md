# Si Phone — инструкции для ИИ-помощника

**Сначала прочитай `PLAN.md`** в этой папке: что за проект, статус этапов, что осталось, решения Романа, что должно быть установлено.

## Если это новый чат / новый аккаунт / другой ИИ
1. Прочитай `PLAN.md` целиком.
2. Проверь окружение по разделу 7 `PLAN.md` (базы, навыки, плагины, сканеры, вход в `gh`, состояние git: ветка `redesign`, последний коммит, тег `before-redesign`, `npm install` / `npm run build` в `mini-app`). Доложи Роману, что есть и чего не хватает; ставь недостающее только с его согласия.
3. Загрузи навыки `design-base` и `security-base` и работай по ним.
4. Продолжай со следующего этапа из раздела 4 `PLAN.md`.

## Правила
- Работаем **по одному этапу, этап — целиком**: делаем все пункты этапа за один заход (не останавливаемся на 5.1, 5.2…; варианты на выбор — с переключателем, показываем вместе в конце) → показываем вживую и коротко говорим, где что смотреть → «ок» или правки Романа → коммит **локально** в ветку `redesign` (репозиторий — вся папка `si-phone/`) → пауза.
- **Сначала дизайн, потом «внутрянка».** Парсеры цен и работу с базой Роман, скорее всего, будет менять — это обсуждаем с ним после дизайна; до этого не переписывать (кроме исправлений безопасности).
- **Не пушить и не выкладывать** без Романа: пуш в `main` сразу попадает к покупателям (Vercel), выкладка Supabase/бота — вместе с ним.
- Не нажимать «Подтвердить заказ» в локальной версии — она подключена к настоящей Supabase.
- Безопасность — по базе `C:\Users\spice\Desktop\security-base` (навык `security-base`); найденные проблемы исправлять сразу.
- Дизайн — по базе `C:\Users\spice\Desktop\design-base` (навык `design-base`); характер Si Phone сохранять, варианты показывать вживую, решает Роман.
- **После каждого этапа:** обновить `PLAN.md` (статус, коммиты, решения, раздел «История») и журналы баз (`LOG.md`), закоммитить базы.
- Общение с Романом — по-русски, простыми словами.
