## 1. Что это

Telegram Mini App магазина техники Apple **Si Phone** (магазин друга Андрея; дорабатывает Роман).
Магазин пока **не действующий** — правки не критичны, выкладываем всё одним разом в конце.

**Один репозиторий на всю папку `si-phone/`** (с этапа 6; история мини-аппа сохранена). Remote — **`github.com/spisusha/si-phone`** (переименован 23.10.2026, старое имя переадресуется; **публичный — решение Романа**: показывать как проект в портфолио. Поэтому в репозитории никогда не должно быть секретов и личных данных: ключи — только в секретах сервисов, ID админов — секрет `ADMIN_CHAT_ID`; перед каждым пушем — gitleaks). Работаем в ветке **`redesign`** (не запушена).

| Папка | Что внутри | Где работает |
|---|---|---|
| `mini-app/` | React 19 + TypeScript + Vite + Zustand + Supabase (каталог, корзина, оформление, админка) + серверные функции `mini-app/supabase/functions/` | Vercel (после этапа 7 — Root Directory `mini-app`), Supabase |
| `bot/` | Telegram-бот на Cloudflare Workers (кнопка «Открыть магазин», FAQ, отзывы, ответы Gemini), wrangler 4 | Cloudflare Workers, воркер `si-phone-bot` (сейчас в Cloudflare работает старый `telegram-bot-andrew`) |
| корень | `PLAN.md`, `CLAUDE.md`, `AGENTS.md`, `NEXT-CHAT-PROMPT.md`, `README.md`, `.gitignore`, `.claude/launch.json` | — |

- Живой мини-апп сейчас: `https://mini-app-andrew.vercel.app` (Vercel публикует из GitHub → **пуш = сразу у покупателей**). Новый адрес после этапа 7: **`https://si-phone.vercel.app`** (на 23.10.2026 свободен) — он уже прописан в боте (`MINI_APP_URL`) и в CORS серверных функций.

## 3. Как запустить локально

```
cd mini-app
npm install
npm run dev        # http://localhost:5173
npm run build      # проверка сборки
```
В Claude Code desktop — сервер `mini-app` из `.claude/launch.json` (в корне `si-phone`).
Вне Telegram (в браузере) системных кнопок Telegram нет — экраны показывают свои; тема — по настройке системы.
