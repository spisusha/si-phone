Магазин пока **не действующий** — правки не критичны, выкладываем всё одним разом в конце.

**Один репозиторий на всю папку `si-phone/`** (с этапа 6; история мини-аппа сохранена). Remote — **`github.com/spisusha/si-phone`** (переименован 23.10.2026, старое имя переадресуется; **публичный — решение Романа**: показывать как проект в портфолио. ## 3. Как запустить локально

```
cd mini-app
npm install
npm run dev        # http://localhost:5173
npm run build      # проверка сборки
```
В Claude Code desktop — сервер `mini-app` из `.claude/launch.json` (в корне `si-phone`).
Вне Telegram (в браузере) системных кнопок Telegram нет — экраны показывают свои; тема — по настройке системы.
