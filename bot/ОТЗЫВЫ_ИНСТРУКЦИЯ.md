# Как добавлять отзывы через бота

## Первая настройка

1. Напиши боту команду `/myid`
2. Скопируй свой `chat_id` из ответа
3. Добавь его в секрет `ADMIN_CHAT_ID` (несколько админов — через запятую, без пробелов):
   ```powershell
   npx wrangler secret put ADMIN_CHAT_ID
   ```
   В `wrangler.toml` id админов не пишем: репозиторий может быть открытым. Секрет начинает работать сразу, без нового деплоя.

## Добавление отзыва

1. Напиши боту `/addreview`
2. Отправь **фото** отзыва (скриншот, фото чека и т.п.)
3. Отправь **текст** отзыва
4. Готово — отзыв сохранён

Чтобы добавить ещё — снова напиши `/addreview` и повтори шаги.

## Отмена

Если передумал — напиши `/cancel`.

## Просмотр отзывов

Пользователи видят кнопку «⭐ Отзывы» в меню. При нажатии открывается галерея с кнопками:
- **← Назад** / **Следующий →** — листать отзывы
- **Открыть магазин** — переход в Mini App
- **Поддержка** — контакты

Фото хранятся в Telegram по `file_id` — отдельное хранилище не нужно.
