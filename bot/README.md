# Telegram-бот Si Phone

Бот магазина: открывает мини-приложение, отвечает на частые вопросы, показывает отзывы и связывает с менеджером.
**Без нейросети** — отвечает только готовыми текстами (решение Романа, 24.10.2026). Работает на Cloudflare Workers, воркер `si-phone-bot`.

## Что умеет

- `/start` — приветствие и кнопки: **Открыть магазин** (зелёная), **Все вопросы**, **Отзывы**, **Написать менеджеру** (сразу чат с Артёмом), **Контакты**.
- **Админам** (их chat_id — в секрете `ADMIN_CHAT_ID`) в приветствии видны ещё **Админка** (открывает `/admin` магазина; пароль всё равно нужен) и **Добавить отзыв**.
- **Частые вопросы** — по разделам: заказ и оплата, доставка и самовывоз, товар и гарантия, связь и режим работы. Всё в одном сообщении, без спама.
- **Свободный текст** — бот ищет вопрос по ключевым словам и отвечает готовым текстом; не нашёл — «Напишите менеджеру» с кнопкой.
- **Отзывы** — фото + текст, листаются кнопками. Добавляют админы: кнопка «Добавить отзыв» или `/addreview` → фото → текст (`/cancel` — отмена).
- Команды: `/start`, `/faq`, `/manager`, `/reviews`, `/myid` (узнать свой chat_id).

## Где менять тексты

Всё в `src/config.ts`: приветствие, контакты, вопросы и ответы (`FAQ`), ключевые слова для свободного текста (`keys`), описание бота. После правки — `npm run deploy`.

## Секреты (Cloudflare, в git не попадают)

| Имя | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота из @BotFather |
| `WEBHOOK_SECRET` | случайная строка: Telegram присылает её с каждым сообщением, чужие запросы отклоняются (401) |
| `ADMIN_CHAT_ID` | chat_id админов через запятую |

Локально токен лежит в `.dev.vars` (образец — `.env.example`).

## Выкладка

```
npm install
npm run deploy
```

Полное переключение на новый воркер (секреты из `.dev.vars`, новый секрет вебхука, `setWebhook`) — скрипт:
`powershell -ExecutionPolicy Bypass -File scripts\switch-bot.ps1 -Admins 123,456`. Подробнее — `DEPLOY.md`.

## Хранилище

KV `si-phone-bot-KV`: отзывы (`reviews`) и временное состояние «добавляю отзыв» (`addreview:<chat_id>`, сбрасывается через сутки).
