# Telegram-бот Si Phone

Бот магазина: открывает мини-приложение, отвечает на частые вопросы, показывает отзывы и связывает с менеджером.
**Без нейросети** — отвечает только готовыми текстами (решение Романа, 24.10.2026). Работает на Cloudflare Workers, воркер `si-phone-bot`.

## Что умеет

- `/start` — приветствие и кнопки: **Открыть магазин** (зелёная), **Все вопросы**, **Отзывы**, **Написать менеджеру** (сразу чат с Артёмом), **Контакты**.
- Кнопка «Открыть магазин» открывает **https://si-phone.ru** (переменная `MINI_APP_URL` в `wrangler.toml`; кнопку меню и Main App — менять в @BotFather).
- **Админам** (их chat_id — в секрете `ADMIN_CHAT_ID`) в приветствии видны ещё **Админка** (открывает админку магазина; вход — по Telegram-аккаунту из списка админов) и **Добавить отзыв**.
- **Частые вопросы** — по разделам: заказ и оплата, доставка и самовывоз, товар и гарантия, связь и режим работы. Всё в одном сообщении, без спама.
- **Свободный текст** — бот ищет вопрос по ключевым словам и отвечает готовым текстом; не нашёл — «Напишите менеджеру» с кнопкой.
- **Отзывы** — комментарии покупателей под постом «Ваши отзывы❗️» в группе обсуждений канала @si_ph0ne (бот — админ группы; `REVIEWS_GROUP_ID`, `REVIEWS_POST_ID` в `wrangler.toml`).
  - Новый комментарий → Артёму и Андрею (секрет `REVIEW_CHAT_IDS`, по их числовым ID) с кнопками «✅ Добавить в отзывы» / «Пропустить». Альбом — одним отзывом; ответы самих менеджеров не приходят.
  - Бот показывает отзыв **пересылкой** (сверху «Переслано от …»), под ним «⭐ Отзыв N из M» и листание. Удалил автор комментарий — отзыв пропускается.
  - Для магазина бот хранит копию (имя, дата, текст, file_id фото) и отдаёт её: `GET /reviews`, `GET /reviews/photo/<id>/<n>` (только одобренные).
  - Отзыв не из группы: «Добавить отзыв» или `/addreview` → фото, потом текст (или фото с подписью; без фото — сразу текст) (`/cancel` — отмена).
- **В группах и каналах бот молчит.**
- Команды: `/start`, `/faq`, `/manager`, `/reviews`, `/myid` (узнать свой chat_id).

## Где менять тексты

Всё в `src/config.ts`: приветствие, контакты, вопросы и ответы (`FAQ`), ключевые слова для свободного текста (`keys`), описание бота. После правки — `npm run deploy`.

## Секреты (Cloudflare, в git не попадают)

| Имя | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота из @BotFather |
| `WEBHOOK_SECRET` | случайная строка: Telegram присылает её с каждым сообщением, чужие запросы отклоняются (401) |
| `ADMIN_CHAT_ID` | chat_id админов через запятую |
| `REVIEW_CHAT_IDS` | кому приходят новые отзывы на одобрение (числовые ID Артёма и Андрея; не задан — админам) |
| `SUPABASE_ANON_KEY` | публичный ключ магазина — для ежедневной «побудки» базы |

Локально токен лежит в `.dev.vars` (образец — `.env.example`).

## Выкладка

```
npm install
npm run deploy
```

Полное переключение на новый воркер (секреты из `.dev.vars`, новый секрет вебхука, `setWebhook`) — скрипт:
`powershell -ExecutionPolicy Bypass -File scripts\switch-bot.ps1 -Admins 123,456`. Подробнее — `DEPLOY.md`.

## Хранилище

KV `si-phone-bot-KV`: отзывы (`reviews`: `{group_ids, name, date, text, photos}` или `{file_id, text}`), ожидающие одобрения (`rvp:<id>`, `rvmg:<альбом>:<id>`, живут месяц) и временное состояние «добавляю отзыв» (`addreview:<chat_id>`, сутки).
