# Куда положить токены — пошаговая инструкция

---

## 1. Где взять токен Telegram

1. Открой Telegram.
2. Найди бота **@BotFather** (в поиске введи `@BotFather`).
3. Напиши ему команду: `/newbot`
4. BotFather спросит имя бота — введи, например: `Si Phone`
5. Потом попросит username — введи, например: `siphone_shop_bot` (должен заканчиваться на `bot`)
6. BotFather пришлёт сообщение с **токеном**. Он выглядит так: `7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
7. **Скопируй этот токен** — он тебе понадобится.

---

## 2. Где взять API-ключ Google (Gemini)

1. Открой в браузере: **https://aistudio.google.com/apikey**
2. Войди в свой Google-аккаунт (если не вошёл).
3. Нажми кнопку **«Create API Key»** (Создать API-ключ).
4. Выбери проект (или создай новый).
5. Появится ключ вида: `AIzaSyxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
6. **Скопируй этот ключ** — он тебе понадобится.

---

## 3. Куда положить токены

Есть два варианта: для **локального запуска** и для **деплоя в интернет**.

---

### Вариант А: Локальный запуск (тест на своём компьютере)

1. Открой папку проекта: `C:\Users\spice\Desktop\si-phone\bot`
2. Создай файл с именем **`.dev.vars`** (с точкой в начале).
   - В проводнике: ПКМ → Создать → Текстовый документ → назови `.dev.vars`
   - Или в Cursor/VS Code: ПКМ в папке → New File → `.dev.vars`
3. Открой `.dev.vars` в блокноте или редакторе.
4. Вставь туда (подставь свои токены вместо `ТВОЙ_ТОКЕН`):

```
TELEGRAM_BOT_TOKEN=7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxx
GEMINI_API_KEY=AIzaSyxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

5. Сохрани файл (Ctrl+S).
6. **Важно:** файл `.dev.vars` в списке игнорируемых — он не попадёт в Git и не уйдёт в интернет.

---

### Вариант Б: Деплой в Cloudflare (бот работает в интернете)

Токены вводятся через команды. **Не вставляй их в чат** — только в свой терминал.

1. Открой **PowerShell**.
2. Перейди в папку проекта:

```powershell
cd "C:\Users\spice\Desktop\si-phone\bot"
```

3. Введи команду для токена Telegram:

```powershell
npx wrangler secret put TELEGRAM_BOT_TOKEN
```

4. Нажми Enter. Появится строка: `Enter a secret value:`
5. **Вставь свой токен Telegram** (Ctrl+V) и нажми Enter.
6. Теперь для Google API:

```powershell
npx wrangler secret put GEMINI_API_KEY
```

7. Нажми Enter. Появится `Enter a secret value:`
8. **Вставь свой API-ключ Google** и нажми Enter.

Готово. Токены сохранены в Cloudflare и будут использоваться при деплое.

## 4. Краткая шпаргалка

| Что | Где взять | Куда положить |
|-----|-----------|---------------|
| Токен Telegram | @BotFather → /newbot | `.dev.vars` или `wrangler secret put TELEGRAM_BOT_TOKEN` |
| API-ключ Google | https://aistudio.google.com/apikey | `.dev.vars` или `wrangler secret put GEMINI_API_KEY` |

## 5. Что делать дальше

- **Локально:** `npm run dev` (нужен туннель ngrok, чтобы Telegram достучался до твоего ПК).
- **В интернете:** `npx wrangler login` → `npm run deploy` → установить webhook (см. README.md).
