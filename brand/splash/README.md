# Экран загрузки Si Phone (BotFather)

То, что человек видит, пока мини-апп открывается. Настраивается в @BotFather, в коде ничего менять не нужно.

Предпросмотр — `preview.html` (открыть в браузере).

## Файлы значка

Выбран вариант «силуэт телефона» (Роман, 23.10.2026; монограмма «S» отклонена).

- `si-phone-splash-a-phone-green.svg` — ярко-зелёный `#7ED957`;
- `si-phone-splash-a-phone-darkgreen.svg` — тёмно-зелёный `#287A33`.

Значок — SVG 512×512, один замкнутый контур из прямых отрезков, без дуг, групп и «дырок». Официальных требований к значку Telegram не публикует; по опыту других разработчиков BotFather отклоняет SVG со сложными контурами (дуги, несколько фигур), поэтому значок сделан максимально простым.

## Цвета

|  | Светлая тема | Тёмная тема |
|---|---|---|
| Фон | `#F5F5F7` | `#000000` |
| Значок | `#287A33` | `#7ED957` |

Фон совпадает с фоном магазина, поэтому после загрузки экран не «мигает». В Telegram с темой «как в Telegram» фон магазина берётся из темы пользователя (на iPhone в светлой теме это примерно `#EFEFF4`) — разница с `#F5F5F7` почти не видна.

## Куда вставить

1. Открыть @BotFather → `/mybots` → бот магазина → **Bot Settings** → **Configure Mini App** → **Configure Splash Screen**.
2. Загрузить значок `si-phone-splash-a-phone-green.svg` (если BotFather просит один файл; если есть отдельная настройка цвета значка — задать цвета из таблицы).
3. Задать цвета фона для светлой и тёмной темы из таблицы.
4. Нажать **Open Splash Screen Preview** и проверить на телефоне в обеих темах.

Названия полей в BotFather могут отличаться от этого описания — ориентир: «значок», «цвет фона» для светлой и тёмной темы.
