# Экран загрузки Si Phone (BotFather)

То, что человек видит, пока мини-апп открывается. Настраивается в @BotFather, в коде ничего менять не нужно.

Предпросмотр — `preview.html` (открыть в браузере).

## Файлы значка

Выбран вариант «силуэт телефона» (Роман, 23.10.2026; монограмма «S» отклонена).

- `si-phone-splash-a-phone-green.svg` — ярко-зелёный `#7ED957`;
- `si-phone-splash-a-phone-darkgreen.svg` — тёмно-зелёный `#287A33`.

Значок — SVG 512×512, один замкнутый контур из прямых отрезков, без дуг, групп и «дырок». Официальных требований к значку Telegram не публикует; по опыту других разработчиков BotFather отклоняет SVG со сложными контурами (дуги, несколько фигур), поэтому значок сделан максимально простым.

## Как это устроено на самом деле (проверено 24.10.2026)

- **Цвет значка задать нельзя.** Telegram рисует значок сам — полупрозрачной светлой фигурой поверх фона; `fill` из SVG не используется. Поэтому «белый фон + зелёный телефон» невозможен.
- **Header color** — цвет верхней полоски Telegram (с «Закрыть») во время загрузки, не самого экрана.
- Светлая и тёмная тема — отдельные настройки; тёмная по умолчанию берёт значения светлой.

|---|---|---|
| Светлая и тёмная тема | `#7ED957` (фирменный зелёный) | `#7ED957` |

Значок — `si-phone-splash-a-phone-green.svg` (светлый силуэт телефона на зелёном). Режим запуска Main App — **Fullsize** (как при открытии кнопкой из сообщения бота; в Fullscreen кнопки Telegram ложились поверх шапки магазина).

## Где настраивается

@BotFather → кнопка **Open** внизу чата → бот **Si phone** → **Mini Apps** → **Main App** → **Launch Screen** (вкладки Light Mode / Dark Mode, **Set Splash Icon**, Background color, Header color) → **SAVE**. В выборе цвета код вводится без `#`; если поле в режиме RGB — переключить «⇕» на HEX.

Требование BotFather: SVG с холстом 512×512 и одним элементом `<path>` (наш значок — один контур, 0,5 КБ).
